# Tech Knife - Contribution & Pull Request Workflow

## Workflow Steps
1. **Branch Naming**: Follow `feature/feature-name`, `fix/issue-description`, or `refactor/scope`.
2. **Commit Messages**: Follow Conventional Commits format (e.g., `feat(cms): add article editor modal`).
3. **Pull Request Checklist**:
   - [ ] Passed TypeScript strict compilation (`npm run lint`).
   - [ ] Verified responsive layout across desktop and mobile.
   - [ ] Passes accessibility contrast guidelines.
   - [ ] Includes relevant unit or E2E test specs in `tests/`.
