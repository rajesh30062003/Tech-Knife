# Tech Knife - CMS & Content Management System Guide

## 1. Introduction
The **Tech Knife CMS Engine** (`/cms`) allows marketing, communications, and talent acquisition teams to manage corporate website content, publish thought leadership blog posts, manage career openings, and optimize search engine visibility.

---

## 2. Content Management Workflows

### 2.1 Corporate Web Pages Builder
- Edit content blocks for public pages (Home, Services, Solutions, Industries, Products, Tech Stack, Portfolio).
- Live preview modes for Desktop, Tablet, and Mobile viewports.
- Publish staging changes directly to live production with zero downtime.

### 2.2 Thought Leadership & Tech Blog Publishing
- Author articles in Markdown or Rich Text format.
- Set tags, featured images, author bios, and publication scheduling.
- **SEO Preview**: Interactive Google search result snippet generator with live title and meta description length counters.

### 2.3 Global Career & Internship Manager
- Post job vacancies and global technology internship program details.
- Review student and candidate applications, screen resumes, and move candidates through recruitment stages.
